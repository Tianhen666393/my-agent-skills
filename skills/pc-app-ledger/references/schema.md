# PC 应用台账字段与规范

## 位置与命名

- 存放目录：当前用户文档目录下的 `my-pc-ledger/`。
- 文件命名：`应用安装清单-<设备标识>.xlsx`（例如当前天选 5 Pro 为 `应用安装清单-天选5pro.xlsx`，未来台式机为 `应用安装清单-台式机.xlsx`）。
- 权限与备份：归属于 `my-pc-ledger` 私有 Git 仓库。写入前遵守 `file-backup-cleanup` 规范，在源盘根目录 `.agent_backups/YYYY-MM-DD/应用台账-<hash>/` 下生成备份与中文说明。

## 表格字段定义（极简 6 列）

| 列序号 | 列名 | 说明 | 示例 |
| :---: | :--- | :--- | :--- |
| 1 | **序号** | 递增整数（1, 2, 3...），由脚本自动维护重排，便于看板速览软件总数 | `1` |
| 2 | **软件名称** | 应用程序通用名称，作为本设备表内的唯一匹配主体 | `Altium Designer 24` |
| 3 | **分类与用途** | 简短描述应用类别与核心用途（一句话或数个关键词） | `EDA电路设计与PCB绘制` |
| 4 | **版本** | 真实安装版本；若无固定版本或为免安装版可填 `最新` 或 `未提供` | `24.0.1` |
| 5 | **安装绝对路径** | 真实可执行文件或根安装目录绝对路径，换机/重装找路径必备 | `T:\Electronic\AD24` |
| 6 | **备注** | 任何补充备忘（如免安装绿色版说明、特殊驱动、快捷键或激活注意等），无则留空 | `已配置本地库；免安装版` |

## 格式规范

- 第 1 行：大标题，字号 16pt，粗体，颜色 `#17365D`，行高 32pt。
- 第 2 行：副标题说明，字号 10pt，灰色，注明设备型号与维护日期，行高 26pt。
- 第 3 行：表头，深蓝底色（`#17365D`），白字粗体，居中对齐，行高 30pt。
- 第 4 行起：数据行，字体 Microsoft YaHei 11pt，行高 42pt，垂直居中，开启换行。
- 冻结窗格：冻结前 3 行（`A4` 起滚动）。
- 筛选器：第 3 行自动添加原生下拉筛选器。

## 维护模式

1. **初次勘察 (`survey`)**：通过系统注册表与已知自定义盘符（如 `T:\APP`、`T:\Electronic`），自动提取候选软件清单，供用户审阅确认。
2. **增量登记 (`upsert`)**：平时装了新软件时，直接按名称和路径进行单条追加或更新，自动重排并递增序号。
3. **健康巡检 (`check`)**：检查台账中记录的绝对路径是否存在，标记已被手动删除或移动的失效死链。
4. **一键同步 (`sync`)**：自动调用看板刷新逻辑更新 `README.md`，并执行 Git 提交推送至私有仓库。
