# Markdown 技术文档规范

## 普通文本与公式

- 简单数值、物理量和常用单位用清晰的普通文本，例如 5 kHz、100 Hz、R = 10 kΩ、C = 10 nF、2 Vpp、100 μs。不要为简单单位套 LaTeX。
- 复杂公式、分式、传递函数、多步推导，以及带下标的变量使用规范 LaTeX。简单的下标变量可用行内数学，例如 `$V_{\mathrm{in}}$`；具体分隔符应与目标查看器兼容。
- 复杂公式独占一行，采用显示数学的 `$$` 分隔符；起止分隔符各占一行，公式块上下各留一空行，交给支持 MathJax 或 KaTeX 的 Markdown 查看器渲染。
- 不把需要渲染的公式放入代码块或反引号。只有说明 Markdown/LaTeX 源码时才使用代码展示，并明确这是源码示例。

## 示例

简单参数写成普通文本：

R = 10 kΩ，C = 10 nF，输入信号为 5 kHz、2 Vpp。

以下代码块仅展示公式块的 Markdown 源码；实际技术文档中的公式应移除外层代码围栏：

```markdown
一阶 RC 低通滤波器的传递函数为：

$$
H(s) = \frac{V_{\mathrm{out}}(s)}{V_{\mathrm{in}}(s)} = \frac{1}{1+sRC}
$$

其中，R 和 C 分别表示电阻与电容。
```

## 输出检查与查看环境

- 检查数学分隔符、花括号和环境是否闭合，命令与上下标是否完整；避免乱码、半截 LaTeX 和显示为正文的 `$$`。
- 目标查看器已知时，使用其支持的语法；有可用的渲染或预览能力时，检查实际结果，包括分式、下标、多行推导及中文周围的排版。
- 源码检查通过不等于渲染已验证。无法打开目标预览时，说明尚未验证实际渲染，不声称公式已成功显示。
- 普通 Markdown 查看器若不支持数学渲染，优先说明环境限制，并建议使用支持 MathJax 或 KaTeX 的查看器。不要把公式源码伪装成已渲染的结果。
- 本技能维护 Markdown 表达规范；不要求为此安装软件、转换 PDF 或改变用户指定的交付格式。
