# 台账字段与格式

## 位置与分类

- Excel：当前用户真实文档目录下的 `my-pc-ledger/AI工具安装清单.xlsx`（兼容历史 `AI工具台账/` 路径）；由脚本解析，不写死用户名。可用 `--workbook` 指定其他文件。
- 更新前副本：源盘 `.agent_backups/YYYY-MM-DD/AI工具台账-源路径标识/唯一备份目录/`，原文件名保留，不覆盖。每份附 `备份说明.md` 与机器可读 `backup.json`（原路径、备份生成时间、执行 Agent、原因及备份文件名）。
- 成功登记后，按备份生成时间将本台账超过 30 天的已识别副本及说明整体移入同盘 `.agent_trash/当天日期/`，不物理删除。不在预览、只读或登记失败时归档；不处理其他台账、元数据不明或含额外文件的目录。既有 `backups/` 需另行确认迁移，不自动处理。
- 默认工作表：共用Skill与插件、Codex自带、Claude自带、DeepSeekHarness自带、共用工具。
- 其他应用由其自己的 agent 在明确授权后追加对应工作表；不跨 agent 自检或登记。
- 应用名和来源分类分别存储于工作表归属与“来源 / 范围”列。普通工作表不是启用状态证明。

## 单一真理源架构（SSOT 规范）

在《共用Skill与插件》表中，严格遵循“**一物一行，多应用联合核验**”原则：
1. **单一资产主体**：同一共用 Skill 无论分发给多少个 Agent，在表中均仅占唯一一行，以组件 `name` 为识别主体，严禁按应用分身拆行。
2. **单一真理源路径（path）**：
   - 个人/通用维护技能：统一登记本地 Git 源码仓库根源 `C:\Users\tianhen\Documents\my-agent-skills\skills\<name>`。
   - CC Switch 集中托管的第三方共用组件：登记 CC Switch 分发源 `C:\Users\tianhen\.cc-switch\skills\<name>`。
3. **多应用范围联合记录（apps）**：记录各 Agent 的实际核验状态，格式如 `Codex (已同步生效)；Antigravity (已同步生效)`。各 Agent 登记时仅维护自身对应的标记，不得擦除其他已核实应用的记录。
4. **双重自检核验（Double Verification）**：脚本在执行路径核查时，既核验源码 `SKILL.md` 的真实性，又探针检测当前 Agent 专属运行时目录（如 Antigravity 检查 `.gemini/config/skills/<name>`）的同步状态，彻底防止“源头存在但运行时不可用”的假在线隐患。

## 列

| 请求字段 | Excel 列 | 要求 |
|---|---|---|
| apps | 适用应用 / 核实范围 | 采用多应用联合标注（如 `Codex (已同步生效)；Antigravity (已同步生效)`）；Agent 登记时仅更新或追加自身生效态，保留其他应用的核实信息 |
| kind | 类别 | Skill、插件、工具、运行环境、配置项或组件缓存 |
| name | 名称 | 核实组件身份后填写；在《共用Skill与插件》中作为组件唯一识别主体 |
| purpose | 用途说明 | 简短中文描述功能，优先 1–2 句话 |
| version | 版本 | 来自真实清单、包信息或版本输出；无证据写未提供 |
| status | 当前状态 | 描述总体可用态（如 `已核实源码；多应用已分发同步`、`已安装，维护脚本已验证`） |
| path | 绝对地址 | 单一真理源绝对路径：共用技能统一指向 Git 源码仓库（`my-agent-skills\skills\<name>`）或 CC Switch 托管源（`.cc-switch\skills\<name>`）；应用自带组件指向其私有绝对路径 |
| source | 来源 / 范围 | 个人技能仓库 (Tianhen666393/my-agent-skills)、共用、应用内置、内部下载等实际来源 |
| check | 路径核实 | 脚本双重核验填写：核实真理源 SKILL.md 身份，同时探针核查当前 Agent 私有目录是否已同步生效 |
| checkedAt | 核实日期 | 脚本按 Asia/Shanghai 填写；只更新本次核实范围 |
| notes | 安装备注 | 安装细节、历史版本/路径、测试限制；多应用合并时保留各自历史备注 |

请求示例（路径指向源码真理源）：

```json
{
  "entries": [
    {
      "sheet": "共用Skill与插件",
      "apps": "Antigravity (已同步生效)",
      "kind": "Skill",
      "name": "ai-tool-ledger",
      "purpose": "维护跨 Agent 共用的 AI 工具安装台账。安装、配置或卸载工具、skill、插件后登记记录，支持单一真理源管理与双重路径自检。",
      "version": "未提供",
      "status": "已更新；双重核验通过",
      "path": "C:\\Users\\tianhen\\Documents\\my-agent-skills\\skills\\ai-tool-ledger",
      "source": "个人技能仓库 (Tianhen666393/my-agent-skills)",
      "notes": "跨 Agent 共用技能，统一由 Tianhen666393/my-agent-skills 维护分发；支持自动备份与多应用联合核验"
    }
  ]
}
```

更新匹配键：
- 《共用Skill与插件》：以“工作表 + 类别 + 名称”为匹配键。存在既有记录时执行更新与 `apps` 合并，不新增行。
- 应用自带表：以“当前应用身份 + 工作表 + 类别 + 名称 + 规范化绝对路径”为匹配键。

`remove` 使用同样精确字段，且要求目标路径已不存在。若仍存在，不将台账删除等同于卸载成功。

## 格式

- 第 1 行标题，第 2 行截至日期与该表范围说明，第 3 行表头，数据从第 4 行开始。
- 全部数据行统一 42 pt，字号 11 pt，垂直居中，文本左对齐，表头居中。
- 标题行 32 pt，说明行 28 pt，表头 30 pt。标题和表头不套用数据行高度。
- 每表保持原生 Excel 表格、筛选、隔行底色及前三行冻结；核实异常用条件格式提醒。
- 列顺序：名称、用途说明、适用应用 / 核实范围、当前状态、类别、版本、绝对地址、来源 / 范围、路径核实、核实日期、安装备注。
- 前四列用于日常浏览；路径和备注保留全文，长内容可选中单元格在编辑栏查看。不为了全部显示长路径把所有数据行撑高，不逐行设置不同高度，不缩小文字。
- 空应用表不编造记录。第 2 行注明“等待对应 agent 自检登记”，空数据行不计为组件。
- 更新截至日期与核实日期，当前日期以 Asia/Shanghai 为准。
