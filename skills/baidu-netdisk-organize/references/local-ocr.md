# 本地 OCR（Windows 自带引擎）

用途：读游戏界面文字来判断作品归属，以及识别发票、证书、成绩单这类文字型内容。**全程在本机跑，不联网。**

## 安装

```powershell
& "C:\Users\tianhen\Documents\Codex\_cache\netdisk-organize\venv\Scripts\python.exe" `
  -m pip install winocr
```

装完约 600 KB，它调用的是 Windows 系统自带的 OCR 引擎，不额外下模型。中文识别用 `zh-Hans`。

## 用法

```python
import asyncio, winocr
from PIL import Image

res = asyncio.run(winocr.recognize_pil(Image.open(path), "zh-Hans"))
text = "".join(line.text for line in res.lines).replace(" ", "")
```

## 怎么提高命中率

1. 先对**全量**跑一遍 OCR，把结果按"去掉空格后的整段文字"聚合，统计高频字符串，就能挖出各作品真正独特的界面词，再补进上表。
2. 用作品名 + 角色名 + 地名 + 专用系统名四类一起做词表，只靠作品名命中率很低。
3. 同一款游戏的同一界面 OCR 文本高度一致，先把完全相同的文本归到一个组，再只需判断这些组，工作量会显著下降。

## 注意

- OCR 结果有错别字（例如把"遗器评价"读成"遗器评价"尚可，但"星穹铁道"曾被读成"星穹铁道"），匹配时用**包含**而非全等，并容忍少量错字。
- 文字少的图（纯 CG、摄影、纯色图）OCR 拿不到信息，这类必须靠 CLIP 或人工。
