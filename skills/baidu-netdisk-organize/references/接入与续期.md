# 百度网盘接入与续期

token 是唯一需要人工干预的环节。**新开一个聊天、或者隔一段时间 token 失效，都照这份文档走。**

**快捷入口**：在聊天里直接发一句「**接入网盘**」，agent 会先只读自检、再向你确认，确认后带你走完下面的流程。

## 首次接入（约 1 分钟）

1. 打开官方授权链接（个人体验通道，不需要企业认证）：

   ```
   https://openapi.baidu.com/oauth/2.0/authorize?response_type=token&client_id=QHOuRXiepJBMjtk0esLhrPoNlQyYd0mF&redirect_uri=oob&scope=basic,netdisk
   ```

2. 用户登录百度账号 → 勾选「**在您的百度网盘创建文件夹并读写数据**」→ 点「授权」。
3. 跳转后 **token 只出现在地址栏** `#` 后面（形如 `access_token=123.xxx`），页面正文不会显示。
   用户找不到时直接提醒他去地址栏看。
4. 拿到 token 后按下节保存。

## token 放哪（三选一，按优先级）

| 方式 | 写法 | 适用 |
| --- | --- | --- |
| 命令行参数 | `--token xxxxx` | 临时用一次 |
| 环境变量 | `BAIDU_NETDISK_ACCESS_TOKEN` | 当前会话临时用 |
| **文件**（推荐） | `C:\Users\tianhen\.codex\baidu_netdisk_token.txt`，内容就是 token | **跨聊天长期用** |

推荐文件方式的理由：新开聊天不用再把 token 发一遍，也不会把 token 留在对话记录里。
让用户自己执行下面这行（把 `<token>` 换成实际值）：

```powershell
Set-Content -LiteralPath "$env:USERPROFILE\.codex\baidu_netdisk_token.txt" -Value "<token>" -NoNewline -Encoding UTF8
```

有效期 **30 天**（`expires_in=2592000`）。官方声明体验密钥会不定期变更，不要用于正式环境。

## 新聊天怎么接上

1. 先验证：`python scripts/bdpan.py whoami`
2. 能返回账号名 → 直接开工，什么都不用做。
3. 报错（常见 `errno=110` token 失效、`-6` 权限错误）→ 回《首次接入》重新授权，
   用新 token 覆盖那个文件即可，其余一概不用动。

## 官方把体验通道的密钥改掉了怎么办

**表现**：授权链接打不开，或提示 client_id / 应用不存在。

**处理**：

1. 去官方 MCP 仓库的 README 找**最新**的授权链接：<https://github.com/baidu-netdisk/mcp>
   README 的「使用准备 → 个人用户（限时体验）」一节里有新的 `client_id` 授权链接。
2. 用新链接走一遍《首次接入》拿新 token。
3. 把新链接更新到本文件，旧链接**保留并标注失效日期**，方便下次判断。

## 兜底方案（体验通道彻底关掉时）

- **AList / CloudDrive2 挂载**：依赖长期存在的公共 client_id 或自有授权，不依赖体验通道，是首选兜底。
- **自建开放平台应用**：**不推荐**。2026-06-03 之后创建的应用，文件类接口只能访问
  `/apps/{应用名}`，且未上线审核的应用限制 10 次/小时，没法整理散落在各处的文件。

## 安全

- token 等于整个百度网盘 **30 天的读写权限**。不要贴到公开场合，不要写进清单 CSV、
  移动日志或任何会留在网盘里的文件。
- 想撤销授权：<https://passport.baidu.com/v6/appAuthority>，解除对 `mcp_server` 应用的授权。
